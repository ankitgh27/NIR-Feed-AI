🐄 NIR Feed AI

AI-assisted cattle-feed quality assessment using NIR spectroscopy, machine learning, spectral anomaly detection and computer vision.

View on GitHub Dataset / DOI

What it does

🔬 Nutrition

PLS-based prediction of CP, NDF, ADF and IVDMD from NIR spectra.

💧 Moisture

Separate NIR-domain model for moisture estimation.

🚨 Anomaly Detection

PCA distance and Isolation Forest identify unusual spectral patterns.

👁️ Mould Screening

Optional computer-vision screening for visible mould-like characteristics.

Current limitations

  • NIR nutrition models require local validation against laboratory reference measurements.
  • Moisture uses a separate 950–1650 nm spectral domain.
  • Visible mould screening needs cattle-feed/silage-specific validation.
  • Spectral anomaly detection does not identify a specific contaminant.
  • Prototype interpretation thresholds are not validated veterinary or regulatory standards.

Next step

The key research step is collecting Indian cattle-feed/silage samples with laboratory reference measurements and using them for local calibration and independent validation.

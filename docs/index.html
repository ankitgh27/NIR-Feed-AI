02 · System overview

One pipeline. Multiple AI modules.

The prototype connects spectral preprocessing, regression models, anomaly detection, moisture analysis and visible-mould screening behind a single feed-analysis workflow.

NIR

Nutritional profile

CP, NDF, ADF and IVDMD predictions from 1050 NIR features.

H₂O

Moisture

Dedicated 950–1650 nm moisture model using 141 wavelength features.

△

Spectral anomalies

Scaling, PCA distance and Isolation Forest support spectral screening.

CV

Visible mould

EfficientNetB0-based image screening for visible mould indicators.

04 · Engineering

More than a model: an end-to-end prototype.

The project is structured as a reusable inference pipeline, API layer, computer-vision module and mobile interface rather than a standalone notebook.

01

Reusable inference pipeline

Centralised model loading and feed-analysis logic keeps inference behaviour consistent.

02

FastAPI backend

REST endpoints return structured outputs for application integration.

03

Computer vision

EfficientNetB0 processes 224×224 RGB input with a 0.60 screening threshold.
